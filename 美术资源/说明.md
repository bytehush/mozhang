# 🎨 美术资源库 · 管理规范

> 程序里所有非代码的美术资产统一收在本文件夹，**按类型建子文件夹分类存放**，养成分类好习惯。
> 代码里只引用这里的文件，不在代码里散落美术资产。

## 📁 分类结构

```
美术资源/
├─ 图标/        程序界面图标（SVG 矢量图，当前在用）
├─ 应用图标/    App 应用图标（生图提示词 + 成品图）
├─ 插画/        （预留）场景插画、背景图、装饰图
├─ 头像/        （预留）吉祥物、角色形象
└─ 其他/        （预留）不属于以上分类的素材
```

**规则：新增美术资产时，先判断类型放进对应子文件夹；没有合适分类就新建一个分类子文件夹并在本文件登记。**

## 🖼 图标文件夹规范（美术资源/图标/）

### 应用图标（美术资源/应用图标/）

| 文件 | 用途 |
|------|------|
| 账字图标-透明底.png | 母本（2048×2048，用户用 Seedream 4.5 生成） |
| favicon.png | 浏览器标签页/收藏夹图标（512×512） |
| 提示词.md | Seedream 4.5 提示词库（4 方案） |
| app-icon.ico（项目根目录） | Windows 桌面快捷方式图标（多尺寸 16~256） |

### 技术标准（保证风格统一、不会画歪）

| 项目 | 标准 |
|------|------|
| 格式 | SVG 矢量图（代码可控、无限缩放、变色方便） |
| 画布 | 24 × 24 viewBox |
| 描边 | `stroke="currentColor"`（颜色自动跟随界面文字）+ `fill="none"` |
| 粗细 | 1.8px（细节复杂的图标可用 1.7px） |
| 端点 | 圆头 `stroke-linecap="round"`、圆角 `stroke-linejoin="round"` |
| 造型基础 | 参考开源 Feather Icons（MIT 协议）的成熟几何造型做微调，避免手绘走形 |

### 命名规则

`用途-名称.svg`，用途前缀分三类：

| 前缀 | 用途 | 例子 |
|------|------|------|
| `nav-` | 侧边栏导航图标 | nav-table.svg |
| `action-` | 按钮动作图标 | action-record.svg |
| `ui-` | 界面小控件图标（关闭、菜单等） | ui-close.svg |

### 加载方式

`js/icons.js` 会在页面加载时把 `[data-icon="图标名"]` 元素自动替换为对应 SVG（内联注入，颜色跟随文字）。
加载失败时自动回退显示元素上的 `data-fallback` 备用字符。
