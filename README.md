# 墨账 MoZhang · 多账本记账

一个跑在你自己电脑上的**多账本记账工具**：零依赖、不需要安装任何东西、双击就能用。
为服装厂等多场景设计——内置「计时工 / 计件工 / 通用收支」三种记账模板，也能随用随长出自定义字段；配上「AI 军师」，能帮你查账、算账、分析、甚至直接帮你记账。

> 数据 100% 存在你本机浏览器（localStorage），不上传任何服务器；AI 请求由本地代理直连你自己填的模型厂商，钥匙（API Key）各人填各人的。

---

## ✨ 功能亮点

- **多账本 + 模板驱动**：同时记好几种账；新账种只需在模板注册表里加一份配置（字段、算钱积木、表格列、图表、AI 人设），界面自动跟随
- **渐进自定义**：账本设置里随时加字段（文本/数字/金额）、改名、停用，历史记录自动兼容
- **账本书架**：封面墙 + 3D 翻开动画，像翻一本真的账本
- **AI 军师（Agent 化）**：
  - 模型自主决定是否查数据（寒暄不查、数据问题必查），最多 3 轮工具循环
  - 查数过程以折叠卡片内联展示，**每个数字可溯源**（数据快照面板）
  - AI 记账只产**草稿**：聊天里出确认卡片，程序算钱、二次校验、可撤销
  - 模型不给力时自动降级为「数据直读」，保证任何模型下都不会空手而归
- **多会话 + 滚动记忆**：每本账多个对话，长对话自动滚动摘要
- **数据安全**：一键导出/导入备份（JSON，含全部账本）；隔离/迁移/去重等 A 类自动化测试

## 🚀 快速开始

**方式一：源码运行（推荐开发者）**

```bash
git clone https://github.com/bytehush/mozhang.git
cd mozhang
双击 启动记账APP.bat        # 或命令行运行 node server.js
```

浏览器会自动打开 `http://127.0.0.1:8787`（端口被占自动 +1）。
前提：电脑装有 [Node.js](https://nodejs.org)（除它以外零依赖）。

**方式二：便携版（给朋友用）**

项目支持打包「免安装便携包」（自带 node.exe + 应用 + 启动脚本），解压双击即用，AI 钥匙各填各的。

**AI 军师开通**（可选，免费额度可用）：到 [智谱开放平台](https://open.bigmodel.cn) 或其他 OpenAI 兼容平台（如 DeepSeek）创建 API Key，粘贴到应用「⚙️ 设置 → 模型设置」。详见 [使用说明.md](使用说明.md)。

## 🧰 技术栈

- 原生 HTML/CSS/JS（IIFE 模块，无打包器、无 npm 依赖、无框架）
- [Chart.js](https://www.chartjs.org) 与 [GSAP](https://gsap.com)（已下载到 `libs/`，本地引用）
- Node 内置 `http` 的本地静态服务器 + AI 流式代理（带 SSRF 防护）
- 数据全存 localStorage；云端部署可选（`cloudfunctions/mozhang-ai` 云函数转发，备而未绑）

## 📁 目录结构

```
├─ index.html            入口页面
├─ server.js             本地服务器 + /api/ai AI 代理
├─ js/
│  ├─ templates.js       账本模板注册表（加新账种改这里）
│  ├─ app.js             主逻辑（账本层/导航/悬浮窗/记录表/设置）
│  ├─ chat.js            AI 军师（SSE 流/多会话/工具调用/草稿确认）
│  ├─ charts.js          图表渲染壳
│  ├─ icons.js           SVG 图标注入
│  └─ cloud-config.js    云端部署接入点（可选）
├─ css/style.css         全部样式（鸣潮水墨主题）
├─ libs/                 本地第三方库
├─ tests/                A 类自动化测试
├─ cloudfunctions/       云端 AI 转发云函数（可选部署）
└─ 美术资源/             SVG 图标 + 应用图标
```
