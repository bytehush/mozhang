# [2026-09-05] 侧边栏改版 + 记录合并记录表 + 悬浮窗 + 设置重组（V0.4）

- 类型：功能修改（主类），含少量新能力（多厂商模型）
- 调整版本：V0.3 → V0.4
- 状态：✅ 已完成并验证

## 调整背景

用户提出四点需求：
1. 导航栏改成「隐藏侧边栏」形式（拿不准效果，希望给几个方案）
2. 「记录」合并进「记录表」；记录表顶部放一个**小区域**，装「记录 / 导入账单 / 导出账单」
   三个功能；下面是工作记录明细；再下面是总工时、记录天数、其中加班、累计工资
3. 这些功能点击后**弹出悬浮窗**并聚焦
4. 设置区：删掉「计薪设置」（记录里可单独设时薪，独立卡片多余）和「导入/导出账单」
   （已迁到记录表），新增「通用设置」和「模型设置」（可自定义多家厂商模型）

### 侧边栏方案对比（用户要求给出方案；已实现方案 A）

| 方案 | 说明 | 结论 |
|---|---|---|
| **A（已实现）** | 桌面常驻侧边栏 + 一键收起成 64px 图标细条；手机端抽屉式（汉堡键呼出+遮罩） | 兼顾「隐藏」与效率，收起状态记忆 |

## 具体改动

1. **index.html（重写）**
   - 新增 `<aside class="sidebar">`：印章品牌区 + 4 个导航项（记录表/图表/AI 军师/设置）
     + 版本脚注 + 收起按钮；`<header class="topbar">`：汉堡键（手机）+ 页面标题 + 迎宾签
   - 「记录」标签页删除，表单整体移入悬浮窗 `#modal-record`
   - 记录表页顺序：操作条（✒️记录 / ⬆导入账单 / ⬇导出账单）→ 明细表 → 汇总铭牌卡
   - 新增悬浮窗 `#modal-import`（选文件导入）、`#modal-export`（统计信息+下载）
   - 设置区：通用设置（默认时薪）、模型设置（厂商/接口地址/Key/模型）、数据管理（示例/清空）

2. **js/app.js（重写）**
   - 导航：侧边栏项切换 + 页面标题/迎宾语联动；收起状态存 localStorage 记忆；
     手机抽屉开关 + 遮罩点击关闭
   - 悬浮窗系统：`openModal/closeModal`，打开时焦点移入、Tab 循环圈定、ESC 关闭、
     点遮罩关闭、关闭后焦点还原到触发按钮
   - 导入/导出迁移到悬浮窗；导出前显示记录条数与起止日期
   - 汇总卡顺序改为：总工时 → 记录天数 → 其中加班 → 累计工资
   - 设置：`PROVIDERS` 内置智谱/DeepSeek/通义千问/Kimi/自定义（OpenAI 兼容），
     切换厂商自动带出接口地址和常用模型列表；设置字段新增 provider/baseUrl（旧数据兼容）

3. **js/ai.js**：请求体带上 baseUrl；报错提示改为「设置 → 模型设置」

4. **server.js**：`/api/ai` 支持转发到任意厂商接口。安全校验（必须）：仅 http/https；
   拒绝 localhost/环回/私网/链路本地/保留段（含 DNS 解析后逐一校验 IP）；
   `redirect: 'error'` 防重定向绕过

5. **css/style.css**：新增侧边栏/顶栏/操作条/悬浮窗样式；黄金比例间距体系
   （14 → 23 → 37 → 60px；侧边栏 232 ≈ 143×1.618；悬浮窗宽 618 ≈ 382×1.618；
   顶栏高 60 ≈ 37×1.618）；900px 以下侧边栏变抽屉
