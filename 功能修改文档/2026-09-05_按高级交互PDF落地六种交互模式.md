# [2026-09-05] 按《8种高级交互》落地六种交互模式（V0.5）

- 类型：功能修改（交互体验升级，依据用户提供的《app小程序高级交互.pdf》）
- 调整版本：V0.4.1 → V0.5
- 状态：✅ 已完成并验证

## 调整背景

用户提供《8种高级App和小程序卡片按钮交互设计》PDF（基于「西瓜同学」教程整理），
要求仔细学习后按其要求优化。文档核心理念：**起点 → 变形 → 终点**，
卡片不该凭空出现/消失，让用户清晰感知操作的因果关系。

## 8 种模式与记账本的对应决策

| 模式 | 决策 | 落点 |
|---|---|---|
| 01 POP 从按钮长出来 | ✅ 落地 | 记录/导入/导出三个悬浮窗 |
| 02 COMMIT 按钮三态 | ✅ 落地 | 保存记录、保存通用设置、保存模型设置 |
| 03 FLING 甩动翻页 | ⏭ 跳过 | 程序内无轮播场景 |
| 04 LAYOUT 布局切换 | ✅ 落地 | 记录表新增「表格 ⇄ 卡片」视图切换 |
| 05 FILTER 三条曲线 | ✅ 落地 | 记录表新增筛选「全部 / 仅加班」 |
| 06 TILT 3D 倾斜 | ✅ 落地 | 汇总铭牌卡（桌面鼠标悬停） |
| 07 PEEK 长按菜单 | ⏭ 跳过 | 卡片已有常驻编辑/删除按钮，长按菜单与其重复，且与多选点击存在手势冲突（符合文档应用建议5：用不同触发方式区分手势） |
| 08 SELECT 整页多选 | ✅ 落地 | 记录批量删除 |

遵守文档应用建议：动画 200-400ms；可访问性（`prefers-reduced-motion` 全局降级）；
性能（TILT 仅桌面精确指针启用）；渐进增强（无动效功能完整）；一致性（同类操作同一模式）。

## 具体改动

1. **POP（悬浮窗从按钮生长）— index.html 无需改，js/app.js 重写模态系统**
   - `openModal(id, triggerEl)`：记录触发按钮位置，用 Web Animations 让悬浮窗
     从按钮中心 `scale(.06)` 平移+放大到屏幕中心，冲头回弹曲线 380ms
   - `closeModal()`：原路缩回触发按钮 260ms（ease-in），动画结束后才隐藏
   - 触发按钮已被重渲染移除时自动退化为直接关闭；ESC/遮罩关闭同样回位

2. **COMMIT（一枚按钮三种状态）**
   - 三个保存按钮改为 `commit-btn` 结构：`c-text / c-spinner / c-result` 三层
   - 流程：宽度锁定 → 收缩成圆 46px（350ms）→ 圆形转圈（约 700ms）→
     展开成结果条画出对勾+「已保存/已更新」（350ms）→ 保持 850ms 后复位
   - 「保存记录」先落库刷新列表，再走三态动画，最后关悬浮窗——视线全程不移动

3. **LAYOUT（表格 ⇄ 卡片视图切换）**
   - 新增卡片视图：每条记录一张切角卡（毛笔字日期+星期、金色当日合计、
     正常班行、朱砂加班行、总工时、编辑/删除）
   - 切换用 FLIP：按记录 id 匹配新旧位置，同卡弹簧移动到位（340ms），
     新出现的从 `scale(.88)` 生长（280ms ease-out）
   - 视图偏好存 localStorage（`jigong_ui`）；**窄屏（<900px）首次使用默认卡片视图**
     （手机看表格要横向滚动，卡片是刚需）

4. **FILTER（三种卡片三条曲线）**
   - 筛选控件「全部 / 仅加班」；被筛掉的卡片原地缩小淡出（200ms ease-in）→
     留下的弹簧移动到新位置（340ms spring）→ 被筛回来的从空槽生长（280ms ease-out）
   - 筛选为空时显示专用提示；筛选只隐藏不删数据，切回「全部」原卡回归

5. **TILT（汇总铭牌 3D 厚度 + 高光）**
   - 鼠标悬停汇总卡：`perspective(700px) rotateX/Y ±8°/±10°` 跟随指针，
     暗金高光径向渐变跟随指针位置扫过；移出复位
   - 仅 `pointer: fine` 且未开启减动效时启用（移动端/降级环境自动关闭）

6. **SELECT（整页切换多选态）**
   - 操作条新增「多选」按钮进入（避免与长按手势冲突）；表格视图点击会先切到卡片视图
   - 整页切换：卡片左移让出勾选圈位置、勾选圈弹簧出现、编辑/删除按钮隐藏、
     点卡片主体切换勾选、选中卡金底高亮
   - 顶部标题变为「已选 N 条」（无勾选时提示「点卡片勾选要删除的记录」）
   - 底部升起墨金操作条：已选 N 条 | 全选/全不选 | 删除（朱砂）| 完成
   - 批量删除：被删卡 OUT 缩淡 → 其余卡片弹簧上移（FLIP）→ 退出多选态

7. **新增 4 个图标**（已登记 `美术资源/说明.md` 清单）：
   ui-grid（卡片视图）、ui-check（多选/对勾）、ui-trash（批量删除）、ui-filter（筛选）

8. **Bug 修复**：启动时未同步两个视图容器的显隐状态（手机默认卡片视图显示成了空表格），
   新增 `syncViewVisibility()` 统一管理；`.modal` 原有 CSS 入场动画与 POP 动画叠加冲突，已移除
