# [2026-09-05] 参照鸣潮官网改版主题（V0.3）

- 类型：功能修改
- 调整版本：V0.2 → V0.3
- 状态：✅ 已完成并验证

## 调整背景

用户提出参照《鸣潮》官网（mc.kurogames.com）的风格样式，对记账本整体 UI 再次优化。
鸣潮官网的设计语言是「水墨仙侠 × 科幻」：宣纸浅青底、墨青深色铭牌、青瓷绿主色、
暗金书法字、朱砂红点缀、切角六边形组件、细网格底纹。与 V0.2 的糖果粉可爱风完全不同，
是一次彻底的视觉方向更换。

## 调整前行为

- V0.2「苹果 × 动漫」：粉紫糖果渐变背景、毛玻璃大圆角卡片、针线吉祥物 🧵、
  元气可爱系迎宾语、葡萄紫/天空蓝/玫瑰粉图表配色。

## 调整后行为

- V0.3「鸣潮」主题：宣纸青灰底 + 细网格纹、水墨晕染光斑（青绿/淡金）、
  墨青铭牌头部（金色书法标题 + 双层金框 + 切角）、朱砂印章「账」、
  批注式迎宾签（宣纸底 + 朱砂左线）、切角六边形全组件、
  汇总卡变四色属性铭牌（深底金字发光）、工钱预览变墨玉牌、
  图表换青瓷/亮青瓷/朱砂/暗金配色 + 墨牌金框提示框。

## 具体改动

1. **css/style.css（整体重写）**
   - 配色变量：墨青 `#22322d`、青瓷绿 `#2e7d74`、暗金 `#b08a2e`、亮金 `#d4b45a`、
     朱砂 `#b5382e`、宣纸卡片 `rgba(253,255,253,.82)`
   - `clip-path: polygon(...)` 实现「左上+右下切角」的六边形组件（卡片/按钮/标签/输入框/Toast）
   - 头部改为墨青渐变铭牌：金色内框（::before 描边）、右上角 ◆ 饰钻、
     标题用楷体系书法字（`--font-brush: KaiTi/STKaiti/...`）+ 金色渐变文字
   - 吉祥物改为朱砂印章「账」字（切角方形 + 内衬白框 + 印章浮动动画）
   - `body::before` 加 52px 间距细网格底纹（科幻感）
   - 光斑 recolor 为青绿/淡金，动画保留
   - 汇总卡：深墨底 + 顶边四色 accent（青/金/朱/蓝）+ 右上 ◆ + 悬停发光
   - 表格：青瓷渐变表头 + 亮金表头文字 + 斑马纹
   - 保留：scrollbar-gutter 防偏移、弹性动效、panelIn/cardIn 进场、窄屏适配

2. **index.html**
   - `<div class="mascot">🧵</div>` → `<div class="mascot">账</div>`（印章字）
   - 默认迎宾语 → 「今日工时，落笔为证 ✒️」
   - AI 加载文案 → 「AI 军师正在推演运筹，稍候片刻…」

3. **js/app.js**
   - GREETINGS 五条全部换仙侠文案：
     记录「今日工时，落笔为证 ✒️」/ 记录表「账目分明，心中自有乾坤 📜」/
     图表「观工钱之势，谋进退之度 🌙」/ AI「AI 军师为你推演一二 🎴」/
     设置「工欲善其事，必先利其器 ⚙️」

4. **js/charts.js**
   - 配色表 C：总量线青瓷 `#2e7d74`、正常班亮青瓷 `#4da196`、加班朱砂 `#c4685a`、
     工时总量线暗金 `#b08a2e`
   - 提示框：墨青底 `rgba(22,36,31,.94)` + 金框 + 楷体金字标题
   - 加班条形保留全圆角（半径 5），正常班条形平顶便于堆叠
