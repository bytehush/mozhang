用户："我想统一我的整体 UI 设计。"——逐页巡检 + 在页面里**量出各组件真实样式**
（不靠目测），确认历史迭代留下了四类"语言分裂"：

| 分裂点 | 现状 A | 现状 B |
|---|---|---|
| 主操作按钮 | 书脊「记录」/确认卡「入账」= **金牌墨字** | 表单「保存」/设置「保存」= 墨青底金字 |

## 二、统一后的「墨账设计系统」（四条硬规则）

### 色彩三家族（各司其职，不混用）

- **宣纸（暖纸面）**：全站表面统一为暖纸色系（#fffdf6 / #faf6eb / #f6f2e7），
  取代全部冷白。`--paper` 令牌改暖 + 20 处字面量全部替换 + 备份兜底色改暖；
- **墨青（结构与选中）**：悬浮窗头、表头、侧栏/分段/主体 chips 的**选中态**、
  模板图标章——深青底金字/浅青底，表达"这是选中的/这是结构头"；
- **暗金（主操作与金额）**：**主操作按钮**与**所有金额数字**——全站唯一的高饱和重点；
- **朱砂**：仅警示（错误、危险操作），不参与以上任何语义。

### 组件四规则

1. **主操作 = 金牌墨字**：`.btn.primary` 改为金渐变 + 墨字
   （与书脊「记录」、确认卡「入账」完全同款），悬停金光增强；
   COMMIT 动效状态色同步适配（转圈改墨色、完成态金光）；
2. **算钱 = 宣纸金线块**：`.preview-box` 改为宣纸底 + 2px 金色左线 +
   书法体大字金额（与 `.dc-calc` 同一配方），深色仪表盘语言彻底退役；
3. **区块头两级制**：页级 `h2` = 「◆ + 青瓷至暗金渐变长线」；
   组级 `.group-title` = 「金线左条 + 浅青底 + 切角」——两级全站一致；
4. **表面 = 暖纸 + 暗金细边**：`.card` 描边统一为 `rgba(176,138,46,.26)`
   （与账页/结算行同一"纸边"语言），封面书页（.bs-inner）与弹窗体渐变同步转暖。
