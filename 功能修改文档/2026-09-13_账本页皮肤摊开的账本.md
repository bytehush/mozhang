## 二、实现

### 1. 宣纸底 + 中缝 + 装订边（纯 CSS，零逻辑）

记录表明细卡片加 `ledger-page` 类，用**四层背景**实现全部纹理
（背景永远在内容下方，不影响表格/卡片交互、层级、FLIP 动画）：

1. 左侧装订阴影（26px 渐变）——像书脊处的凹陷；
2. **中缝折线**（页面正中 1px、13% 透明度）——摊开书的立折；
3. **装订缝线**（左侧 14px 处的青瓷色虚线，`repeating-linear-gradient` 定为 1px 宽列）；
4. 宣纸底（#fdfbf4→#faf7ee 纵向渐变）；
   另加金色系描边与内阴影（`inset 0 0 46px` 暗金微光）。

### 2. 页眉（`#page-head`，渲染逻辑约 20 行）

打开的账本页眉一行两端：

```
[账本名（书法字）] [主体·签]        [模板名 · N 天 · 起止日期 · 共 N 条]
─────────────────────────────────────────────（金色细线）
```

- `renderPageHead()`：取活动账本的名称、subject、模板名、记录数与起止日期
  （`TPL().groupByDate`）；空账本显示"暂无记录"；
- 挂在 `renderRecords()` 顶部——**任何数据变化（记账/删除/导入/切账本）都会自动刷新**，
  与整理逻辑零耦合。
