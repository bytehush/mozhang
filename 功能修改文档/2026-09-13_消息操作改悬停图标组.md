# [2026-09-13] 消息操作改悬停图标组：复制/引用数据隐于无形

- 类型：功能修改（界面优化）
- 上线版本：V0.11.2
- 状态：✅ 已完成并验证

## 一、用户反馈

1. 「复制」想要一个**图标**，与对话内容**左对齐**，鼠标**悬停时才出现**，不悬停不出现；
2. 「📦 引用数据」按钮不好看，也不该常驻在消息底下，不符合美学设计——按设计美学优化。

## 二、改法（美学原则：留白 + 低饱和 + 少即是多）

- 操作行默认 **opacity: 0 完全隐形**；鼠标悬停整条 AI 消息（或键盘聚焦 `:focus-within`）
  时 250ms 淡入——平时视线里只有对话本身；
- 「复制」「📦 引用数据」两个文字按钮 → **两个 15px 线性图标**（新增美术资产
  `ui-copy.svg` 双层复制、`ui-data.svg` 数据库，Feather 造型 1.8px 圆头描边、currentColor，
  已登记 美术资源/说明.md），与正文共用 34px 左轴线；
- 图标悬停有**纯 CSS 水墨小贴士**（`::after content: attr(data-tip)`，零 JS）：
  「复制」「引用数据」；引用数据展开时图标保持青瓷高亮表示"开着"；
- **数字核对徽章与图标同行**（原来徽章挤在最底下），徽章是信任标记保持常显、图标悬停显；
- 触屏设备无悬停（`@media (hover: none)`）→ 图标常显，功能不丢失。

## 三、工程

- `js/chat.js`：appendMsg（历史渲染）与 finishExchange（实时收尾）里两段几乎相同的
  操作行构建代码**抽成公共 `buildMsgActions(el, content, snap)`**（返回操作行元素，
  "未查数据"警告徽章由 finishExchange 附加）——消除重复，两处行为保证一致；
- `css/style.css`：新增 .cm-actions 悬停显现 / .ia-btn 图标按钮 / 纯 CSS tooltip；
  删除旧 .cm-copy 文字按钮样式；移动端断点同步（操作行 padding 归零）。

## 四、验证（浏览器实测）

- 默认态截图：操作按钮完全隐形，消息间只剩对话与留白 ✓
- 带 snap 的历史消息：两个图标按钮 + SVG 加载成功 + 徽章同行 ✓
- 点击「引用数据」图标 → 快照面板展开、图标高亮 ✓；点击「复制」正常 ✓
- 全程 `window.__errors` 为 0 ✓
