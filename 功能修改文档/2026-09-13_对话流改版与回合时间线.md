# [2026-09-13] AI 军师对话流改版：过程与回答融合 + 回合时间线 + 滚动条隐藏

- 类型：功能修改（界面改版）
- 上线版本：V0.11.0
- 状态：✅ 已完成并验证

## 一、用户反馈的三个问题

1. **过程与结果割裂**：思考过程、工具调用、最终回答"像是分开的没有联系的"，
   且 V0.10.0 的工具大卡片视觉权重太高，"比最终结果还明显"；
2. **滚动条突兀**：全局滚动条常驻显形，"感觉好突兀挡视线"，希望做成隐藏的；
3. **多轮对话无法快速定位**：希望"一个对话对应一个锚点"，多轮对话可快速锚定；
4. 附带：全局有些地方文字过多，繁琐不高级（参照知乎美学帖：留白、节奏、低饱和、少即是多）。

参照物：用户提供的 ZCode 对话截图——过程行（思考/终端/编辑）都是**一行式轻量条目**
（图标+动词+对象+状态，灰色小字），嵌在输出文字流中；回答正文是主角。

## 二、改法

### 1. 叙述流融合（核心）

- AI 消息结构改为「头像行 + `cm-body`（过程行区 `cm-acts` + 正文）」；
- **`cm-body` 左缘一条细竖线**（青瓷色渐变淡线）把思考行、工具行、正文串成一体——
  一个回合在视觉上是一个连续的叙述，不再是散落的卡片；
- **思考气泡（圆点+推演中）删除**，改为 ZCode 式思考行：进行中显示「💭 思考中」
  （实时思考文本进可展开区），首字到达后收成 **「💭 思考 · N 秒」**，点击可展开思考内容；
- **工具大卡片改一行式过程行**：「🔧 查询账本统计 · 服装厂计时工 ✓」，低饱和灰调小字，
  点击行展开真实查询结果（左线轻面板，不再是带边框的大卡片）；
- **纯寒暄自动留白**：没有工具调用也没有思考内容时，过程行区整体隐藏，一句话直接回答；
- 层级由对比度表达（美学帖的"低饱和弱化过程、强化结果"）：过程行 12px 灰调，
  正文 14px 正常墨色，主角唯一。

### 2. 回合时间线（锚点导航）

- 对话区右缘新增 **锚点列**：每个 AI 回合一个横向刻度，默认低透明度（.55），
  悬停整列时显形——"隐藏的"不挡视线；
- **悬停刻度**显示该回合的用户提问摘要（自绘水墨小贴士，非原生 title）；
- **点击刻度**平滑滚动到对应回合；当前视口所在回合刻度自动高亮（暗金色）；
- 实现要点：`renderTimeline()` 按 AI 消息 offsetTop/scrollHeight 比例布点；
  消息渲染完、交换完成、切换账本、窗口 resize 时重算；**页面未激活时高度为 0 的坑**——
  先临时显形再测量，且 app.js 的 switchTab 切到对话页时调 `JGChat.onShow()` 重算。

### 3. 滚动条全局隐藏

- WebKit + Firefox 双方案：滚动条轨道全透明、滑块透明，**悬停可滚动区时才淡入细滑块**；
- 从此静态界面看不到任何滚动条，视线干净。

### 4. 文案精简（留白）

| 位置 | 改前 | 改后 |
|---|---|---|
| 空状态标题 | 我是 AI 军师，读过你这本账的全部记录 | 这一本账，我已读毕 |
| 空状态副题 | 点下面的问题直接开问，或自己在下方输入： | 删除（chips 本身就是入口） |
| 输入框占位 | 问点什么…（Enter 发送） | 问问你的账… |
| 输入坞提示 | Enter 发送 / Shift+Enter 换行 | Enter 发送 |
| 清空按钮 | 清空本会话 | 清空（说明进悬停提示） |
| 数字核对徽章 | ✓ 数字核对：回答中 4 个数字均来自工具查询结果 | ✓ 4 个数字均有出处 |
| 未查数据警告 | △ 本回答未查询账本数据，其中 3 个数字没有数据来源（需要准确数字可让 AI 先查账本） | △ 未查账本，数字仅供参考 |

## 四、验证（模拟厂商 SSE 端到端）

- 数据问题：过程行序列「💭 思考 · 1 秒 → 🔧 查询账本统计 ✓ → 🔧 查询每日明细 ✓」
  与正文同列融合，两次请求的 tools/assistant(tool_calls)/tool×2 结构正确 ✓
- 纯寒暄「你好」：过程行区自动隐藏，直接流式回答 ✓
- 时间线：4 个回合 4 个刻度、悬停提示显示该轮提问、点击跳转滚动 ✓
- 历史消息 reload 后按新行式渲染 ✓；全程 `window.__errors` 为 0 ✓
- 附带发现：即便厂商把 content 与 tool_calls 混在同一轮流式返回，Agent 循环
  也能正确处理（先流正文、再拼装工具调用、继续循环）——鲁棒性顺带验证 ✓

## 五、遗留

- 思考行展开的思考文本不持久化（刷新后历史消息只显示「思考 · N 秒」行本身），
  与旧版一致（reasoning 从不入库存）；
- 锚点刻度超过约 40 回合后间距会拥挤（悬停提示仍可区分），后续可做折叠分组。
