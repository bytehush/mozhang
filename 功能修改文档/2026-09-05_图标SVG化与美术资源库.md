# [2026-09-05] 图标 SVG 化 + 建立美术资源库（V0.4.1）

- 类型：功能修改（图标实现方式更换）+ 资产管理规范建立
- 调整版本：V0.4 → V0.4.1
- 状态：✅ 已完成并验证

## 调整背景

用户提出：程序里的图标目前用的是 emoji，希望换成**代码可控绘制**的图标；
同时担心「大模型手绘 SVG 容易画得难看」。并要求先建立**美术资源文件夹**，
里面按类型分类（先建「图标」子文件夹），以后图标类美术资源都归档在这里。

## 应对「画不好」的措施

1. 所有图标造型以开源 **Feather Icons（MIT 协议）** 的成熟路径为基础微调，
   不凭空手绘复杂造型（齿轮、钢笔、托盘等都是经过多年打磨的几何形状）
2. 统一技术标准：24×24 画布、1.8px 圆头描边（细节图标 1.7）、`currentColor`
   跟随界面文字变色、圆角端点
3. AI「军师」图标用四角星光（双星）造型——曲线星形是最不容易走形的画法
4. 全部图标放大到 44px 逐个截图目检，确认无变形后才交付

## 具体改动

1. **新建 `美术资源/` 文件夹 + `美术资源/说明.md` 管理规范**
   - 分类结构：`图标/`（在用）、`插画/`、`头像/`、`其他/`（预留）
   - 图标命名规则：`用途-名称.svg`（nav- / action- / ui- 三类前缀）
   - 内含图标清单表（文件名、内容、使用位置），新增图标必须登记

2. **新建 11 个 SVG 图标文件（美术资源/图标/）**
   - nav-table（表格）、nav-chart（柱状图）、nav-ai（四角星光）、nav-settings（齿轮）
   - action-record（钢笔）、action-import（托盘+下箭头）、action-export（托盘+上箭头）
   - ui-close（叉号）、ui-menu（三横线）、ui-collapse（双箭头）、ui-folder（文件夹）

3. **新建 `js/icons.js` 图标加载器**
   - 页面加载时把 `[data-icon="图标名"]` 元素自动注入对应 SVG（内联，颜色跟随文字）
   - 图标文件请求结果带缓存；加载失败自动回退显示 `data-fallback` 备用字符
   - 暴露 `window.JGIcons.mount()` 供动态内容使用

4. **index.html**：16 处 emoji 图标全部换成 `data-icon` 挂载点
   （侧边栏 4 个导航、收起按钮、汉堡菜单、操作条 3 个按钮、3 个悬浮窗标题、
   3 个关闭按钮、导入提示文件夹图标）；相关文案里的 emoji 引用同步清理；
   引入 icons.js；版本脚注改为 V0.4.1

5. **css/style.css**：新增 `.ico/.bi/.mh/.dt-ico` 图标盒样式（flex 居中、
   svg 铺满、currentColor 继承）；按钮改为 inline-flex 对齐图标与文字；
   选中导航项的金色小钻从图标前移到文字前

6. **js/ai.js**：报错文案去掉「⚙️」引用（设置入口不再带 emoji）

- ✅ 放大 44px 逐个目检：造型端正、粗细一致、无变形
- ✅ 颜色自动适配：侧边栏默认青灰、选中金、主按钮金字、纸按钮墨字
- ✅ 导入悬浮窗：标题托盘图标、文件夹提示图标、关闭叉号均正常

## 影响范围

- 图标通过本地服务器加载（`美术资源/图标/`），程序必须照常从「启动记账APP.bat」进入；
  万一图标文件缺失或被移动，界面自动回退显示原 emoji，不影响功能
- 以后加新图标：先把 SVG 放进 `美术资源/图标/` 并在说明.md 登记清单，
  再在页面里用 `<span data-icon="名称" data-fallback="原emoji"></span>` 引用
