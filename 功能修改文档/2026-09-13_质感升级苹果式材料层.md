# [2026-09-13] 质感升级：苹果式"高级感"材料层（V0.15.2）

- 类型：功能修改（视觉质感）
- 上线版本：V0.15.2
- 状态：✅ 已完成并验证

## 一、需求

用户："我想要我的页面设计更加有高级感，更加有质感，我觉得苹果的设计给我这种感觉。"
——保留水墨身份，把苹果设计的**材料层**手法移植进来。

## 二、苹果"高级感"的实质拆解 → 落地

| 苹果手法 | 本项目实现 |
|---|---|
| **多层柔和阴影**（不是一坨黑，是 1px 极浅 + 中景 + 远景三层） | `--shadow-card` = 1px/2px(.04) + 6px/18px(.055) + 22px/52px(.07)；浮层 `--shadow-pop` 三层更深 |
| **材料感毛玻璃**（vibrancy：模糊 + 饱和度增强） | 卡片 `blur(22px) saturate(1.2)`；顶栏 `blur(22px) saturate(1.3)`；遮罩 `blur(10px)` 且透明度降低（.5→.42，露出底下层次） |
| **发丝描边**（0.5-1px 极低对比） | 新增 `--hairline` 令牌：表格行分隔、顶栏底线全部换发丝；卡片金边 alpha 再降（.26→.20） |
| **顶部高光**（材质受光的"上缘亮线"） | 新增 `--sheen`（inset 0 1px 0 白 .62）铺在卡片/弹窗/顶栏 |
| **纸纹颗粒**（材质不是纯色） | 新增 `--grain`：SVG feTurbulence 噪点 data-URI（2.8% 透明度）铺在卡片/弹出层/侧栏——屏幕上出现"看得见的纸" |
| **数字对齐**（数据表格精度感） | 表格 `font-variant-numeric: tabular-nums`，金额列纵向严格对位 |
| **克制的灰阶** | 表格斑马纹/悬停底色减淡（.045→.032 / .1→.075），层次靠阴影与留白而非颜色 |
