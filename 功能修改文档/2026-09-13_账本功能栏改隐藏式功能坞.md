# [2026-09-13] 账本功能栏改隐藏式功能坞

- 类型：功能修改（界面优化）
- 上线版本：V0.14.4
- 状态：✅ 已完成并验证

## 一、需求

用户："把账本的功能那块区域做成隐藏的形式。"——账本页顶部的操作按钮行
（书架/记录/导入账单/导出账单/多选）与"摊开的账本"皮肤并排时视觉干扰大，
希望平时收起来，保持干净的账页观感。

## 二、设计（延续项目"隐藏式"交互语言）

- 顶部只留一条**细抓手**（居中的「···」小页签，悬停变青瓷色，带说明提示）；
- **悬停抓手区域**或**键盘聚焦**（Tab 到按钮）时，功能栏滑出（透明度 + 上移 +
  展开高度三重过渡，弹簧缓动）；
- **点按抓手**可固定展开（触屏友好），**点外部**自动收起；
- **触屏设备**（`@media (hover: none)`）自动常显——无悬停能力时功能不丢；
- 收起 = `max-height: 0 + opacity: 0 + pointer-events: none`（项目全局
  `box-sizing: border-box`，可安全折叠到 0）；展开 = `max-height: 120px`——
  用 max-height 过渡实现平滑展开/收起，账页随之上移/下移。

## 三、实现

- `index.html`：操作条外包一层 `#fn-dock`（功能坞）+ `#fn-handle`（抓手）；
- `css/style.css`：`.fn-dock` 系列样式与三态（收起/悬停或聚焦/固定展开）、
  触屏媒体查询兜底；
- `js/app.js`（initNav）：抓手点击切换 `.fn-open`；document 级点击在坞外时
  移除 `.fn-open`。

## 四、验证（浏览器端到端）

- 默认收起：功能栏 `max-height:0 / opacity:0 / pointer-events:none`，
  抓手可见 ✓
- 点抓手：展开（`max-height:120px / opacity:1`）、`.fn-open` 标记 ✓
- 点外部：自动收起 ✓
- 展开后按钮功能正常（点「记录」正常弹出记账悬浮窗）✓
- 截图确认：账页上方只剩一枚极简抓手，账本页干净 ✓；全程零报错 ✓

## 五、涉及文件

`index.html`、`css/style.css`、`js/app.js`（共 3 处小改动，无逻辑侵入）。
