# [2026-09-13] 账页结算行 + 墨条工具栏（设计升级）

- 类型：功能修改（界面设计升级，用户提出"功能栏与四个总计不美观/不高级"）
- 上线版本：V0.14.5
- 状态：✅ 已完成并验证

## 一、需求

用户："功能栏目的布局，还有最下的四个总计，看着不太美观，显得不高级，审美太低了。
最终页面要符合账本的设计哲学，兼具美观独特、清晰直观、操作方便。"

## 二、设计（把两处 UI 收回"账本语言"）

账本设计哲学 = 宣纸底 / 墨青题头金字 / 青瓷 / 暗金书法 / 朱砂 / 切角 / 留白低饱和。
对照检查：四个总计是**深色方块铭牌**（通用仪表盘语言，与"账纸"打架）；
功能栏是**纸白药丸按钮行**（通用工具栏语言）。两者都离开账本语言，故显廉价。

### 1. 四个总计 → 「账页结算行」（写进账纸的合计行）

- **位置**：从账页外移进账页内（`#summary-cards` 移入 `.ledger-page`），
  成为账纸页脚——真实账本的样子：表格之后一行"合计"；
- **形态**：金色细线（与页眉同款）收口，四列均分，列间暗金细分隔线；
- **文字**：标签小字灰调、加大字距；数值用**书法字（KaiTi）23px**——
  像账页上手写的合计；金额用暗金、负数用朱砂；
- **去噪**：删掉深色底、◆角标、悬浮抬升与发光——纸面上不需要这些；
- 窄屏（≤560px）自动两列。

### 2. 功能栏 → 「墨条」（墨青底、暗金描边、金字）

- **形态**：收起的抓手从小浅签改为**墨色小签（金字 ●●●）**；
  展开后是一条**居中的墨条**——墨青渐变底 + 暗金细描边 + 切角，
  与账页题头（悬浮窗头）同一套"墨底金字"语言；
- **布局（分组）**：`[◀ 书架] │ [✒ 记录] [⬇ 导入账单] [⬆ 导出账单] [☑ 多选]`
  ——「书架」是返回动作，用一条暗金细线与工具组分开；
  **「记录」是唯一主按钮**（金牌金底，暗色字）——全页只此一处高饱和，
  视线自然落在"记一笔"上，符合"清晰直观、操作方便"；
- 其余按钮为低饱和米白文字，悬停时浮出淡金底；隐藏/唤出三态交互不变
  （悬停/聚焦滑出、点抓手固定、点外收起、触屏常显）。

### 3. 顺带退役：TILT 汇总铭牌倾斜（V0.5 交互之一）

原 3D 倾斜 + 高光是为深色铭牌设计的；纸面结算行不适用，故退役
（删除 `initTilt` 与相关 CSS，代之以注释说明）。其余五种交互（POP/COMMIT/
LAYOUT/FILTER/SELECT）不受影响。

## 三、验证（浏览器实测 + 截图）

- 墨条：墨青渐变底 + 暗金描边 + 切角生效；按钮米白、悬停淡金；
  「记录」金底暗字、「书架」右侧金线分隔 ✓
- 结算行：在账页内（`closest('.ledger-page')` 为真）、金色上线收口、
  四列等宽（实测 208px × 4）、数值书法字 23px ✓
- 截图确认：整页为「墨条悬于账页之上 + 账纸表格 + 金线结算行」的统一语言 ✓
- 全程 `window.__errors` 为 0 ✓
