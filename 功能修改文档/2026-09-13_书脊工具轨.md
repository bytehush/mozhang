# [2026-09-13] 书脊工具轨：操作挂在账本的书脊上

- 类型：功能修改（界面设计，探索"不悬浮"的第三种形态）
- 上线版本：V0.14.6
- 状态：✅ 已完成并验证

## 一、缘起（用户反馈）

用户对 V0.14.5 的"墨条工具栏"仍不满意："设计的还不是很好，探索一下更加巧妙
不悬浮在正上方的形式"。核心症结：墨条无论怎么美化，本质仍是**浮在页面上方的
一条工具栏**——通用软件语言，没有长进账本自身。

## 二、设计（三段演化，第三段定稿）

| 版本 | 形态 | 问题 |
|---|---|---|
| V0.14.4 | 隐藏式功能坞（●●● 抓手，悬停滑出） | 藏得太深，且展开时占页面正上方 |
| V0.14.5 | 居中墨条（墨底金字） | 好看些了，但仍是"悬浮横条" |
| **V0.14.6** | **书脊工具轨** | **不悬浮、不占位——工具栏化作"书脊"本身** |

**形态**：账页左缘长出一条**墨色书脊**（墨青渐变 + 暗金描边），操作竖排挂在上面——
像真实账本的书脊索引签：

```
┌──┬──────────────────────┐
│◀ │  服装厂计时工 [我]      │
│书│  ────────────────     │
│架│  工作记录明细 …        │
│✒ │  ┌────────────────┐   │
│记│  │  账目表格        │   │   ← 工具在书脊上，
│录│  └────────────────┘   │      账页从书脊右侧展开
│⬇ │  ── 结算行 ──         │
│导│                       │
│出│                       │
│☑ │                       │
│多│                       │
│选│                       │
└──┴──────────────────────┘
```

**巧在哪**：

1. **不悬浮**：书脊是 `ledger-shell` 的结构件（flex 布局），与账页左缘**严丝合缝
   贴合**（实测 gap=0）——它不是"放在页面上方"，而是"账本的一部分"；
2. **随卷轴生长**：`position: sticky`——长表格滚动时，书脊上的工具一直跟着你；
3. **竖排双字**：writing-mode: vertical-rl，书架/记录/导入/导出/多选两字竖排——
   呼应账页的书法字与中缝，而不是横排按钮；
4. **唯一金牌**：「记录」是金底墨字的主按钮——全页唯一高饱和点，视线自动聚焦；
5. **操作方便**：常驻可见（不再有"藏太深"的发现成本），点一下就到；
6. **窄屏自适应**：≤900px 自动转为页面之上的横排墨条（in-flow，非悬浮），功能不丢。

## 六、补记（同日）：书脊通高——长度与账本动态一致

用户追加要求："功能栏长度要和账本动态一致"。原书脊按内容收缩成一小截（约 358px），
与整本账不等长。改法：

- `.ledger-shell` 去掉 `align-items: flex-start`，书脊作为 flex 项**自动拉伸到与账页等高**
  （flex 默认 stretch）——账本多长，书脊就多长，动态一致；
- 账页原 `margin-bottom` 移至 shell（避免书脊比账页多出 16px）；
- sticky 从书脊本体移到内层 `.rail-inner`（书脊通高后本体不再需要 sticky，
  由内层工具组承担"随滚动跟随"）。

### 途中挖出并修复两个"sticky 隐形杀手"

调试发现工具组不跟随滚动，逐层审计祖先后揪出两个隐蔽成因：

1. **`panelIn` 入场动画的 `fill: both`**——动画结束后把最终 transform
   （恒等矩阵 `matrix(1,0,0,1,0,0)`）**永久钉在面板上**；恒等矩阵也是 transform，
   会改变后代的定位上下文，使**面板内所有 `position: sticky` 静默失效**。
   改为 `fill: backwards`（结束时释放 transform，视觉无任何变化）。
   `cardIn` 同理一并修正。
2. **翻开转场收尾漏清 workbench 的残留 transform**——返回转场清了 `work`，
   翻开转场只在首段清 `[shelf, inner, ...others]`，`work` 的 `translate: none;
   rotate: none; scale: none; transform: translate(0px,0px)` 一直残留。
   补上：`gsap.set([shelf, inner, ...others, work], { clearProps })`。

### 通用教训

**`position: sticky` 的隐形杀手清单**：祖先的 `overflow`（本次没有）、
**入场动画 `fill: both` 残留的恒等 transform**（本次①）、
**JS 动画框架漏清的内联 transform**（本次②）——排查方法：从 sticky 元素
逐层向上打印 `computedStyle` 的 transform/overflow/clip-path，找出非 none 的祖先。
