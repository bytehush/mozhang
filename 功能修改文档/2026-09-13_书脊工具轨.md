# [2026-09-13] 书脊工具轨：操作挂在账本的书脊上

- 类型：功能修改（界面设计，探索"不悬浮"的第三种形态）
- 上线版本：V0.14.6
- 状态：✅ 已完成并验证

## 一、缘起（用户反馈）

用户对 V0.14.5 的"墨条工具栏"仍不满意："设计的还不是很好，探索一下更加巧妙
不悬浮在正上方的形式"。核心症结：墨条无论怎么美化，本质仍是**浮在页面上方的
一条工具栏**——通用软件语言，没有长进账本自身。

## 二、设计（三段演化，第三段定稿）

| 版本 | 形态 | 问题 |
|---|---|---|
| V0.14.4 | 隐藏式功能坞（●●● 抓手，悬停滑出） | 藏得太深，且展开时占页面正上方 |
| V0.14.5 | 居中墨条（墨底金字） | 好看些了，但仍是"悬浮横条" |
| **V0.14.6** | **书脊工具轨** | **不悬浮、不占位——工具栏化作"书脊"本身** |

**形态**：账页左缘长出一条**墨色书脊**（墨青渐变 + 暗金描边），操作竖排挂在上面——
像真实账本的书脊索引签：

```
┌──┬──────────────────────┐
│◀ │  服装厂计时工 [我]      │
│书│  ────────────────     │
│架│  工作记录明细 …        │
│✒ │  ┌────────────────┐   │
│记│  │  账目表格        │   │   ← 工具在书脊上，
│录│  └────────────────┘   │      账页从书脊右侧展开
│⬇ │  ── 结算行 ──         │
│导│                       │
│出│                       │
│☑ │                       │
│多│                       │
│选│                       │
└──┴──────────────────────┘
```

**巧在哪**：

1. **不悬浮**：书脊是 `ledger-shell` 的结构件（flex 布局），与账页左缘**严丝合缝
   贴合**（实测 gap=0）——它不是"放在页面上方"，而是"账本的一部分"；
2. **随卷轴生长**：`position: sticky`——长表格滚动时，书脊上的工具一直跟着你；
3. **竖排双字**：writing-mode: vertical-rl，书架/记录/导入/导出/多选两字竖排——
   呼应账页的书法字与中缝，而不是横排按钮；
4. **唯一金牌**：「记录」是金底墨字的主按钮——全页唯一高饱和点，视线自动聚焦；
5. **操作方便**：常驻可见（不再有"藏太深"的发现成本），点一下就到；
6. **窄屏自适应**：≤900px 自动转为页面之上的横排墨条（in-flow，非悬浮），功能不丢。

## 三、实现与清理

- `index.html`：工作台重构为 `.ledger-shell = .spine-rail + .card.ledger-page`；
  **按钮 id 全部保留**（btn-shelf/btn-add/btn-import/btn-export/btn-select），
  JS 事件零改动；
- `css/style.css`：新增 `.spine-rail`/`.rail-btn`（含 sticky、竖排、金牌主按钮、
  窄屏横排）；**删除**已退役的 `.fn-dock/.fn-handle/.action-bar` 全部样式及其
  媒体查询残留；
- `js/app.js`：**删除**功能坞的抓手切换/点外收起监听（该机制完成历史使命退役）。
