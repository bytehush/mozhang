# [2026-09-18] 便携分享版与云端接入点

- 类型：新功能开发
- 上线版本：V0.15.5
- 状态：✅ 已完成并验证

## 需求描述

用户想把当前进度的应用**方便地分享给朋友使用**。经方案对比（云端网址 / 便携包 / 小程序），用户嫌云端方案的一次性授权步骤繁琐，选定**便携包**路线：给朋友一个压缩包，放到电脑桌面、双击即可启动，电脑上什么都不用装。云端网址路线完成代码层准备后暂时搁置，随时可续。

## 功能设计

**便携包**（本次交付）：
- 一个 zip（约 37MB）= 免安装 node.exe（官方 v22.23.2）+ 应用全部运行文件 + `启动墨账.bat` + `先看我-使用说明.txt`
- 朋友：解压 → 双击 bat → 浏览器自动打开 http://127.0.0.1:8787 → 关黑窗口即退出
- 数据存朋友自己浏览器 localStorage，各人独立；备份走设置页导出/导入
- AI 军师：朋友在设置里填自己的免费钥匙（智谱 glm-4-flash 等），与作者钥匙互不相干

**云端接入点**（备而未用）：
- AI 请求地址抽象为 `aiEndpoint()`，默认仍 `/api/ai`（本地零变化）
- 新增 `js/cloud-config.js`：`window.MOZHANG_CLOUD=null`；云端部署时替换为 `{ aiProxy: '云函数地址' }`，前端即自动改走云端转发
- 新增 `cloudfunctions/mozhang-ai/`：HTTP 云函数（9000 端口 web 服务器形态），移植 server.js 转发逻辑 + SSRF 校验 + SSE 流式透传 + CORS 头
