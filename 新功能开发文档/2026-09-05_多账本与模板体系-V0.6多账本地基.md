## 需求描述

让 App 从"只会记计时工一种账"升级为**多账本体系**：内置三种记账模板
（计时工/计件工/通用收支），可同时建多本账、随时切换，各自独立记录、汇总、图表、AI 分析。
本期（V0.6）是路线图第一期「多账本地基」，后续 V0.7 渐进自定义字段、V0.8 AI 一句话建账。

## 功能设计

### 数据架构（新增"账本层"）

```
模板（js/templates.js，代码内置，含函数）
  ├─ hourly  计时工：时间段×时薪（跨零点进位），正常班+加班
  ├─ piece   计件工：数量×单价
  └─ general 通用收支：收入−支出=结余
账本（localStorage jigong_ledgers）
  └─ { id, name, templateId, settings:{默认时薪/单价}, createdAt }
记录（jigong_led_<账本id>，按账本分键）
  └─ { id, v:{原始字段}, m:{模板compute算出的指标} }   ← 与旧扁平结构不同，迁移转换
界面偏好（jigong_ui）→ { 账本id: {view, filter} } 按账本各自记忆
```

- **记录统一形态 `{v, m}`**：v 是用户填的原始值，m 是模板算钱积木算出的指标，
  表格列/卡片/汇总/图表全部从这两个对象取数
- **安全积木**：时长×时薪、数量×单价、收入−支出。模板只能声明积木组合，不存在任意公式

### 界面

- 侧边栏顶部**账本切换器**：显示当前账本（图标+名称），点开菜单列出全部账本
  （带记录条数）＋「新建账本」＋「账本设置」；收起态只留图标
- **新建账本悬浮窗**：三张模板选择卡（图标+名称+一句话说明）→ 账本命名 →
  按模板填默认参数（计时工=两个时薪、计件工=单价、收支=无）→ 创建（COMMIT 动效）
- **账本设置悬浮窗**：改名 + 默认参数 + 危险区（删除账本，双确认）
- 表单/表格列/卡片/汇总卡/筛选选项/图表/AI 人设全部由当前账本的模板动态生成：
  - 筛选：计时工=全部/仅加班；收支=全部/仅收入/仅支出；计件=只有全部（控件自动隐藏）
  - 图表：计时工=工资折线+工时混合；计件=工钱折线+件数条形；收支=收支柱形+结余折线、累计结余
  - AI：每个模板独立人设与统计口径（报告自动贴合账本类型）
- 设置页「通用设置（时薪）」卡片移除（并入账本设置），保留模型设置与数据管理

### 数据迁移（旧版本自动升级）

- 首次打开：旧 `jigong_records`（扁平结构）→ 转换为 `{v,m}` → 建入「服装厂计时工」账本
- 旧时薪设置带入账本 settings；原始旧数据留存备份键 `jigong_records_v1_backup`
- 迁移完成弹 toast 告知

### 备份兼容

- 导出升级 **v2 格式**：{ver:2, ledgers:[{...账本, records}]}，全部账本一个文件
- 导入：v2 按账本合并（同账本内按模板 signature 去重）；**v1 旧备份仍可导入**
  （自动转新结构并入计时工账本）
