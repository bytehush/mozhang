# [2026-09-05] 多账本与模板体系 · V0.7 渐进自定义字段

- 类型：新功能开发
- 上线版本：V0.6 → V0.7
- 状态：✅ 已完成并验证
- 方案依据：[多账本与模板体系-方案推演](2026-09-05_多账本与模板体系-方案推演.md)（路线图第二期「账本随用长」）

## 需求描述

让每个账本支持**渐进自定义**：用户用账本时发现缺一列（如"布料款""翻新次数"），
随时在账本设置里加字段、改字段名、停用字段——表单、表格、卡片自动跟上，
**历史记录新字段留空**（不报错、不回填）。用户全程不需要理解"模板"这个词。

## 功能设计

### 字段定义（存放在账本对象上）

```js
ledger.customFields = [
  { key: 'c_xxx', kind: 'text'|'number'|'money', label: '布料款', enabled: true }
]
```

- 三种**安全积木类型**：文本 / 数字 / 金额（元）。不开放任意公式（沿用 V0.6 的可靠性原则）
- key 建后不变（uuid），改名只改 label——历史数据按键取值，改名零迁移
- `enabled: false` = 停用：界面全部隐藏，**数据保留**，可随时启用恢复
- 从账本删除字段 = 连历史记录里该字段的值一并剥离（双确认 + 提示先备份）

### 显示规则

| 位置 | 规则 |
|---|---|
| 表单 | 模板表单之后追加「自定义字段」分组；金额类型 step=0.01，文本占整行 |
| 表格列 | 追加在模板列之后、操作列之前；空值显示 —；金额格式化为 ¥ |
| 卡片 | 值非空才显示行（`标签：值`），插在卡片主体与底栏之间 |
| 编辑 | 打开编辑时自动回填已有值；历史记录无值则留空 |
| 去重签名 | 导入合并的签名 = 模板签名 + 已填的自定义值（同班次不同备注不会误合并） |

### 管理界面（账本设置悬浮窗内新增「自定义字段」区块）

- 已有字段一行一个：类型徽标 + 名称输入框（即时改名）+ 启用勾选 + 删除按钮
- 底部「添加」行：选类型 + 填名称 + ＋添加（同名字段拦截）
- 编辑期间操作**草稿**，点「保存账本设置」才生效（COMMIT 动效）；删除字段在保存时统一剥离历史值

### 备份兼容

- v2 导出包含每本账的 customFields（**修复：首版导出遗漏该字段**）
- v2 导入按 key 合并字段定义（同键以备份为准），历史值随记录一并恢复
- 无 customFields 的旧 v2 备份照常导入（视为无自定义字段）
