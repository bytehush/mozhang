# [2026-09-05] 修复 AI 军师发消息后无输出

- 类型：bug 修复（行为不对：有思考动画但没有回答）
- 修复版本：V0.8 → V0.8.1
- 状态：✅ 已完成并验证

## 问题现象

用户在 AI 军师对话里发了一句问话，AI"思考了一会"，然后**什么也没有输出**
（没有回答，也没有报错提示）。

## 排查过程

1. 用用户的真实配置在页面里发了一次原始流式请求，抓到厂商原始返回：
   **HTTP 401 `令牌已过期或验证不正确`**——即 API Key 无效（当前 key 只有 17 位，
   智谱的 Key 通常是 30 多位、中间带点的长串，疑似复制不完整或已重置）
2. 复现确认：对话的错误路径本身是好的，无效 key 会在气泡里红字显示 401 提示；
   用户看到"没有输出"最可能是提示出现前就离开了页面，或把红色提示当成了"没反应"

## 根本原因与修复

**根本原因**：API Key 无效（厂商 401），不是对话功能故障。

**顺带加固（真实流式此前从未用有效 key 跑过，把潜在坑提前排掉）**：

| 加固点 | 说明 |
|---|---|
| SSE 换行兼容 | 解析前统一 `\r\n`/`\r`/`\n` 三种换行（SSE 规范都允许，厂商/网关实现不一） |
| 残留冲刷 | 流结束时把没有以空行结尾的最后一条事件也处理掉 |
| 空输出自动降级 | 流式全程没吐出任何内容时，自动改用非流式请求重试一次（结果照常打字机输出） |
| 思考型模型提示 | 若因 finish_reason=length 且无内容，明确提示换非思考型模型 |
| 401 引导 | Key/令牌类错误在气泡里附「去模型设置检查 →」跳转按钮 |
| Key 过短提醒 | 保存设置时若智谱 Key 少于 20 位，toast 提醒可能是复制不完整 |

## 验证结果

- ✅ CRLF 换行的 SSE 流解析成功（修复前失败）
- ✅ 无结尾空行的残留事件冲刷成功
- ✅ 空流自动降级：第二次非流式调用返回内容并正常打字机输出
- ✅ 401 错误气泡出现「去模型设置检查 →」按钮，点击跳转设置页
- ✅ 保存设置时短 Key 出现过短提醒

## 用户需要做的事

**到「⚙️ 设置 → 模型设置」重新复制一把有效的智谱 API Key**
（open.bigmodel.cn → 控制台 → API Keys → 复制完整的 `数字.字母` 长串），
保存后再问 AI 军师即可正常对话。
