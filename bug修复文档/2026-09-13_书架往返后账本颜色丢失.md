# [2026-09-13] 修复：账本往返书架后颜色全变绿（主题色被清空）

- 类型：bug 修复（显示不对）
- 上线版本：V0.14.2
- 状态：✅ 已修复并验证

## 现象（用户报告）

选中一本账本、点击进入、再退出回书架后，**所有账本封面的颜色都变成了绿色**
（之前每本按模板各有一色：计时工青绿 #43a79a、收支淡蓝 #7ba7bc）。

## 根因（已复现确认）

封面卡的模板配色写在内联样式里：`<span class="bs-card" style="--bs-accent:#43a79a">`，
CSS 用 `var(--bs-accent)` 给书脊/描边/印章上色。

转场收尾时用了 **`gsap.set(el, { clearProps: 'all' })`**——`'all'` 会清掉元素的
**整个内联 style 属性**，把内联写的 `--bs-accent` 一并擦除；颜色随即回退到
`var(--bs-accent, #2e7d74)` 的默认青绿色。所以每次"退出书架"后所有封面都变绿。

复现证据：返回前两卡 `style="--bs-accent:#43a79a"` / `"#7ba7bc"`（书脊
rgb(67,167,154) / rgb(123,167,188)）；返回后 style 属性清空，两卡书脊均变
rgb(46,125,116)（默认绿）。

（该问题 V0.13.2 引入容器变换时就已潜伏，V0.14.1 转场增强后更易被注意到。）

## 修复（js/app.js）

不再全清，改为**只清 GSAP 真正动过的属性**：

```js
const SHELF_TL_CLEAR = 'transform,opacity,zIndex';   // 转场收尾清理清单
gsap.set([shelf, inner, ...others], { clearProps: SHELF_TL_CLEAR });
```

共 5 处 `clearProps:'all'`（翻开 2 处、返回 3 处）全部替换为清单式清理；
全项目已无 `clearProps:'all'`。

## 验证（浏览器端到端）

- 完整往返 **两轮**（含时间跳跃模拟快速操作）：
  两本账的颜色变量完整保留（`--bs-accent: #43a79a` / `#7ba7bc`），
  书脊颜色各自不变，不再统一变绿 ✓
- 卡片内联样式**无任何 transform/opacity 残留**（说明转场清理依然生效，
  只是不再误伤主题色）✓
- 全程 `window.__errors` 为 0 ✓

## 涉及文件

`js/app.js`（新增 SHELF_TL_CLEAR 常量 + 替换 5 处 clearProps）。

## 通用教训

**`clearProps:'all'` 会清掉元素整个内联 style——凡是内联承载了业务样式
（CSS 变量、主题色、背景图 url 等）的元素，禁用 `'all'`，必须列清单**。
本项目此后所有 GSAP 收尾清理一律使用属性清单。
