# [2026-09-13] 修复：多选后账本宽度变窄

- 类型：bug 修复（显示不对）
- 上线版本：V0.14.8
- 状态：✅ 已修复并验证

## 现象（用户报告）

"账本宽度在多选之后怎么变窄了"——进入多选、甚至退出多选后，整页账本都变窄了，
且回不到原来的宽度。

## 根因（已复现量化）

书脊工具轨上线（V0.14.6）后，工作台改为 flex 布局：
`.ledger-shell = .spine-rail（58px）+ .card.ledger-page`。

**账页作为 flex 子项，宽度默认由"内容"决定**（`flex-basis: auto`，且
`min-width: auto` 不允许收缩到内容宽度以下）：

- 表格视图：表格内容较宽 → 账页 ~859px（甚至**隐性溢出容器约 43px**）；
- 多选会强制切换到**卡片视图**（`enterSelect → applyView('cards')`），
  卡片内容较窄 → 账页缩到 **522px**；退出多选后视图停留卡片 → 宽度也回不来。

量化证据：账页宽度 表格 859px → 多选后 522px（shell 恒为 874px）。

## 修复（css/style.css 一行）

让账页始终**占满剩余宽度**，与内容无关：

```css
.ledger-shell .card.ledger-page { flex: 1 1 auto; min-width: 0; margin-bottom: 0; }
```

- `flex: 1 1 auto`：吃满书脊以外的全部宽度；
- `min-width: 0`：允许在窄屏正常收缩（表格自身已有 `overflow-x: auto`）。

## 验证（浏览器端到端，量宽断言）

| 状态 | 账页宽 | 说明 |
|---|---|---|
| 表格视图 | **816px**（= 874 − 58 书脊） | 满宽且**右侧不再溢出** ✓ |
| 多选中（卡片视图） | **816px** | 不再缩窄 ✓ |
| 退出多选 | **816px** | 保持满宽 ✓ |

四个状态切换全程零报错；截图确认卡片视图满宽铺开、账页与书脊等长。

## 涉及文件

`css/style.css`（`.ledger-shell .card.ledger-page` 增加 flex 占位与 min-width）。

## 通用教训

**flex 行内的内容容器（表格/卡片/列表）若依赖"自动宽度"，其宽度会随内容类型跳变**
——凡是"主内容区"，一律显式 `flex: 1 1 auto; min-width: 0`，把宽度决定权
从内容手里收回到布局手里。
