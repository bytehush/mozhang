# [2026-09-06] 修复设置页白屏变形 + 模型设置改 ZCode 式档案（V0.9.2）

- 类型：bug 修复（设置页结构断裂）+ 功能修改（模型设置重设计）
- 调整版本：V0.9.1 → V0.9.2
- 状态：✅ 已完成并验证

## 一、设置页白屏变形（bug 修复）

### 现象

切到设置页后首屏一片白，往下拉页面变形错乱。

### 根因

改模型菜单位置时多写了一个 `</div>`，把 `<main>` 容器提前闭合——
**整个设置页掉到了 main-wrap 外面**，失去全部布局样式（居中/宽度/内边距全丢）。
DOM 审计确认：`tab-settings` 的父级变成了 body，前一兄弟是 main-wrap。

### 修复

删除多余的闭合标签，设置页回归 main 内。实测：首张卡片 top 从 835px（视口外）
回到 119px（正常位置），三张卡片布局恢复。

## 二、模型设置改 ZCode 式档案（功能重设计）

### 旧设计的问题

厂商下拉框 + 固定预设模型列表：快切菜单会冒出一堆**没配置过的**模型名；
也无法自定义上下文窗口、最大输出等参数。

### 新设计（用户点名参照 ZCode）

**一个 API 配置（接口地址 + Key）可以挂多个模型档案**，每个档案可自定义：

| 参数 | 说明 |
|---|---|
| 显示名称 | 快切菜单里显示的名字 |
| 模型 ID | 实际请求用的模型（如 glm-4-flash） |
| 上下文窗口 | 千 tokens（影响长对话容量） |
| 最大输出 | tokens（限制单次回答长度） |

- 设置页：模型列表行内直接编辑（当前模型 = 圆点选中），＋添加 / ✕ 删除（带确认）
- 厂商**快捷填入**：智谱 / DeepSeek / 通义 / Kimi 一键填接口地址
- 对话页模型快切菜单**只显示配置好的模型**（显示名 + 模型 ID 子行）＋「管理模型 →」跳设置
- 请求自动携带当前档案的 model 与 maxTokens（服务器按档案限幅 256~32768）

### 数据结构（向后兼容）

```js
settings.models = [{ id, label, model, context, maxOut }]
settings.currentModelId
```
旧设置（单 model 字符串）首次加载自动迁移为一个默认档案（沿用原模型与 Key）。
