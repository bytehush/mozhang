账本说明

每种账是一个「账本」，在左侧切换；账本名称和默认时薪/单价等参数，在左侧账本菜单的「账本设置」里调整。

模型设置

一个厂商 = 一套 API（接口地址 + Key）+ 多个模型，各自独立保存：切换厂商标签后，之前填过的 Key 会自动带出，没填过就重新填。切到哪个厂商，对话就用哪家的 API。

模型列表（当前厂商可配置多个模型）

点模型行左侧圆点选用当前模型；对话页的模型快切菜单只显示各厂商已配置好的模型。

显示名称模型 ID上下文(K)最大输出

智谱 glm-4-flash 免费：浏览器打开 open.bigmodel.cn → 注册/登录 → 控制台 → API Keys → 创建并复制完整 Key。

数据管理

所有数据只保存在这台电脑的浏览器里（localStorage）。导入、导出备份已移到「记录表」页顶部，建议定期导出备份文件。

账本设置

自定义字段

给这本账加专属栏目（如"布料款""翻新次数"），表单、表格、卡片会自动跟上；历史记录里没填过的留空。停用的字段数据保留，删除则连历史值一起清掉。

危险区

删除账本会连同里面的全部记录一起删除且无法恢复，建议先在「数据管理」导出备份。

导入账单

选择之前「导出账单」生成的 JSON 备份文件。导入的记录会与现有记录合并（按日期+时段自动去重），备份里的通用/模型设置也会一并恢复。

点击下方按钮选择备份文件（.json）
